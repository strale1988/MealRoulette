# Meal Roulette

Stuck on what to cook? Spin for it. An offline-first PWA (vanilla JS, no framework, no build step needed to run): cook from your fridge, plan days, pizza dough lab, fermentation station, Craft tools, and a cookbook shelf of 2,600+ recipes.

## Run it
Serve the folder with any static server (`python3 -m http.server`) and open `index.html`. It must be served, not opened from disk (service worker, scripts).

## Folder map
```
index.html            page markup, small boot scripts and the loader (the FILES list = load order)
sw.js                 offline cache (network-first); its list is generated by build.py
manifest.webmanifest  PWA manifest
css/app.css           the whole stylesheet, in layers (later sections override earlier ones)
icons/  fonts/        assets
js/core/              kitchen.js (recipe rules), engine.js (meal generator), xlink.js, dinner.js
js/craft/             Craft tools: craft-lib (helpers), craft-*.js (tool data), craft-pizza, craft-ferment, craft-ui (the page)
js/ui/                the app screens, loaded after everything else, in the order listed in FILES
data/ingredients.js   the ingredient catalog
data/cookbook/        recipes: cuisines/ (one file per cuisine) and general/ (no cuisine)
data/cookbook.bundle.js   GENERATED from data/cookbook/, never edit
tools/                checkers and tests
docs/                 cookbook.md (recipes, catalog, shelf, pizza) and craft.md (Craft tools)
build.py, build.bat   bundle + sync + check
```

## Load order (index.html `FILES`)
`js/core/kitchen.js`, `data/ingredients.js`, the recipe bundle, `js/craft/*`, `js/core/xlink.js`, `js/core/dinner.js`, `js/core/engine.js`, then `js/ui/*` (core, tabs-and-search, controls, roulette, display, plan, pizza-night, cooking-mode, spinner, pizza-dough, nudges-and-log, shake, results, share-and-install, shelf, app-extras). The UI files are one program cut into pieces: they share top-level variables, so keep their order.

## Everyday workflow
1. Edit recipes in `data/cookbook/...`, ingredients in `data/ingredients.js`, screens in `js/ui/`, styles in `css/app.css`.
2. `node tools/check.js` (recipes), `node tools/smoke.js` (Craft calculators), `node tools/check-links.js` (loader / offline list / links).
3. Before deploying: `python3 build.py build` (or double-click `build.bat`). It rebuilds the bundle, syncs `sw.js` and bumps the cache version.
   `python3 build.py check` reports problems without changing anything. After editing a font, icon or CSS file use `build.bat bump`.
4. Browser tests (need Playwright once): `node tools/nav-test.js`, `node tools/shelf-test.js`.

More detail: `docs/cookbook.md`, `docs/craft.md`.
